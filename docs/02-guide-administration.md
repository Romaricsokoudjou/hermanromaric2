# Guide d'administration

Connexion : `/connexion` avec un compte d'équipe → bouton « Administration ». Le menu n'affiche que les modules autorisés.

## Rôles
| Rôle | Périmètre |
|---|---|
| Super administrateur | Tout, y compris administrateurs et permissions |
| Administrateur | Tout sauf gestion des administrateurs |
| Gestionnaire des inscriptions | Utilisateurs, inscriptions, notifications |
| Gestionnaire financier | Paiements, finance, portefeuilles, retraits, REWARDS |
| Gestionnaire de contenu | Formations, centres, contenus, médias, HERMAN AI, notifications |

Créer un compte d'équipe : *Administrateurs* → « Créer un compte d'équipe » (mot de passe requis). Le dernier super administrateur ne peut pas être rétrogradé.

## Modules
- **Formations / Tarifs** : modifier textes, photos, objectifs, compétences, débouchés ; chaque durée (3 mois, 6 mois, 1 an) a son prix, ses frais d'inscription/polo, ses tranches et son interrupteur « Proposée ». Les tarifs seedés sont ceux de la grille officielle ; **vérifier quelles durées chaque formation propose réellement** et désactiver les autres.
- **Règle de cumul** (Tarifs) : tant qu'elle est « non définie », toute candidature à plusieurs formations passe en *validation administrative* (Inscriptions → saisir le montant final).
- **Centres, Enseignants, Galerie, Vidéos, Actualités, Témoignages, Documents** : *Contenu* (formulaires + téléversement). Les trois espaces vidéo (`presentation`, `formations`, `temoignages`) n'affichent que des vidéos publiées ; sinon un message neutre est affiché. Ne publier que des contenus authentiques.
- **Textes, FAQ, légal, logo** : clés `history`, `vision`, `mission`, `commitments`, `faq.referral`, `referral.terms`, `legal.*`, `brand.logo` (URL du logo).
- **Document officiel / agrément** : *Documents* → type « agrement » (affiché sur la page Institution).
- **Médiathèque** : téléverser / remplacer / supprimer ; copier l'URL.
- **HERMAN AI** : base de connaissances (réponses officielles), activation, conversations.
- **Paramètres** : téléphones, WhatsApp, réseaux, arrêté, mentions (RCCM, NIU… à renseigner seulement s'ils sont officiels).
- **Audit** : journal immuable de toutes les opérations sensibles.
